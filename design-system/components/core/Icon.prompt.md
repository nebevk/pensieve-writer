Lucide glyph at Pensieve's 1.75 stroke.

```jsx
<Icon name="search" size={15} />
```

`name` is one of Icon.names (check, settings, search, list, alignLeft, undo, redo, image, link, comment, newNote, listTodo, rain, flame, moon, x, arrowRight, plus…). Use stroke 2–2.25 only inside small solid buttons.
