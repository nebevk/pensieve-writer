# Pensieve

A cozy, minimal desktop writing app for Windows: projects of books, stories and articles, chapters and
parts, notes and to-dos, a Book view, Zen mode, in English and Slovenian.

- What it does: [docs/requirements.md](docs/requirements.md)
- What is open: [docs/backlog.md](docs/backlog.md)
- Building and running it: [docs/SETUP.md](docs/SETUP.md)
- Publishing a version: [docs/releasing.md](docs/releasing.md)
- Rules for coding agents: [AGENTS.md](AGENTS.md)

Run it with `npm install` and `npm run tauri dev`.
